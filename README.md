# Demogorgon Tamagotchi 🐾👾

Интерактивная 3D-игра в стиле "Тамагочи", посвященная Демогоргону из сериала "Очень странные дела". Проект написан на React с использованием React Three Fiber для отрисовки 3D-модели.

## 🔗 [Живая демонстрация]([https://demo-pet-new.layero.app/](https://demo-pet-new-main.layero.app/))

## 🛠 Технологии
*   **React** (Vite)
*   **React Three Fiber** & **Drei** (для 3D-графики)
*   **Web Audio API** (для генерации звуков и фонового гула без внешних файлов)
*   **CSS3** (анимации, адаптивность, эффект CRT-монитора)

## ✨ Особенности
*   **3D-модель**: Вместо статичной картинки — интерактивная 3D-модель Демогоргона.
*   **Геймплей**: Следи за шкалами сытости и энергии, иначе монстр проснется!
*   **Нарастающая сложность**: Чем дольше играешь, тем быстрее падают показатели.
*   **Система рекордов**: Лучшее время выживания сохраняется в `localStorage`.
*   **Случайные аномалии**: Внезапные всплески из Наизнанку, которые пугают и сбрасывают статы.
*   **Атмосфера**: Зловещий фоновый гул, эффект старого телевизора, глитч-анимации и летающие споры.
*   **Мультиязычность**: Поддержка русского и английского языков.
*   **Адаптивность**: Игра корректно отображается на мобильных устройствах.

## 🚀 Запуск локально
1. Клонируйте репозиторий: `git clone ...`
2. Установите зависимости: `npm install`
3. Запустите сервер разработки: `npm run dev`
